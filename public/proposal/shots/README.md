# 제안 화면 스크린샷

여기에 받은 이미지를 아래 이름 그대로 넣으면 화면이 채워집니다.

| 파일 | 화면 |
| --- | --- |
| `home.png` | 홈 (첫 진입) |
| `login.png` | 로그인 |
| `guest.png` | 비회원 이용 |
| `history.png` | 작업 이력 |
| `settings.png` | 설정 |

- 형식은 PNG, 가로폭은 이미지 원본 그대로면 됩니다. 화면 폭에 맞춰 늘어납니다.
- 파일이 없으면 그 자리에 어떤 파일이 필요한지 안내가 나옵니다. 히트박스는 그대로 동작합니다.
- 버튼 위치는 `public/assets/js/shot.js` 의 `SCREENS` 에 % 로 적혀 있습니다.
  오른쪽 위 **히트박스** 버튼을 누르면 위치가 눈에 보입니다.
