무인과금 복합기 UI/UX 개선안

실제 복합기 사용 환경을 가정한 인터랙티브 TO-BE 목업입니다. 각 화면을 선택하면 화면 전환과 주요 설정 인터랙션을 직접 확인할 수 있습니다.

전체 이용 흐름

1대기 · QR 연결 → 2서비스 선택 → 3설정 → 4결제 → 5작업 → 6완료

결제가 먼저입니다. 복합기에서 설정을 마치고 결제를 요청하면 휴대폰에서 결제하고, 결제가 확인되면 복합기에서 따로 누르는 것 없이 작업이 자동으로 시작됩니다.

화면

대기 · QR 연결 휴대폰을 QR로 연결하고 이용할 서비스를 고릅니다. 화면 바로가기 → 복사 설정 컬러·양단면·부수를 고르면 미리보기가 따라 바뀝니다. 화면 바로가기 → 복사 진행 설정과 예상 금액을 확인하고 결제를 요청합니다. 화면 바로가기 → 스캔 해상도·색상·파일 형식을 고르고 결제를 요청합니다. 화면 바로가기 → 팩스 수신처와 전송 설정을 고르고 결제를 요청합니다. 화면 바로가기 → 결제 휴대폰 결제를 기다리고, 확인되면 작업이 자동으로 시작됩니다. 화면 바로가기 → 작업 완료 끝난 작업과 결제 금액을 확인하고 추가 이용 여부를 고릅니다. 화면 바로가기 →
인쇄는 복합기 화면이 없습니다 인쇄는 휴대폰에서 파일을 고르고 결제까지 마칩니다. 복합기는 출력만 합니다. 그래서 대기 · QR 연결 화면의 인쇄 카드는 안내이고, 눌러서 넘어가는 화면이 없습니다.
개발 참고사항 보기

화면 크기

1920 × 1080으로 그려 놓고 브라우저 크기에 맞춰 비율 그대로 줄입니다. 복합기는 해상도가 정해진 기기라 반응형으로 늘이지 않습니다. 실제 기기 해상도가 다르면 assets/device.js의 BASE 한 곳만 고치면 됩니다.

단가 규칙이 정해지면 assets/device.js의 PRICE 한 곳만 고치면 됩니다. 설정 화면에서 계산한 금액은 requestPay()가 그대로 들고 가므로 결제 화면과 완료 화면에 같은 값이 나옵니다.

파일

파일내용
assets/device.css색·간격·부품 스타일. 색은 :root 변수로 빼 두었고 body[data-svc]로 복사·스캔·팩스를 바꿉니다.
assets/device.js화면 크기 맞추기, 고른 설정 들고 다니기, 요금 계산, 결제 요청·확인
assets/icons.js그림 조각. <i data-ico="home">로 씁니다
각 화면 .html화면 하나당 파일 하나. 빌드 과정이 없어 그대로 열립니다

설정을 고르는 버튼은 data-set="copy.color=color"처럼 적어 두면 같은 무리끼리 하나만 켜지고 값이 저장됩니다. 화면을 옮겨도 고른 설정이 이어집니다. 화면 이동은 data-go="copy.html"로 답니다.

상태는 sessionStorage에 둡니다. job.pending은 결제를 기다리는 한 건, job.list는 결제가 끝나 실행된 건입니다.

AS-IS와 비교하려면

나란히 놓고 보거나 개선 항목을 확인하려면 검토 보드의 복합기 영역에서 보십시오. 보드의 프로토타입 보기가 이 목업을 그대로 띄웁니다.

※ 사용자명, 금액, 작업 건수 등은 목업 확인을 위한 예시값입니다.
